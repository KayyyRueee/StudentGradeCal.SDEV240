# Student Grade Calculator

## Description
This Windows Forms application calculates a student's current grade and estimated grade based on assignment scores.

## Features
- Validates student ID
- Allows class selection
- Displays assignment information
- Calculates current grade and letter grade
- Calculates estimated grade and letter grade
- Validates estimated scores
- Includes Clear and Exit buttons

## How to Use
1. Enter a valid student ID.
2. Click **Load Class**.
3. Select a class.
4. Enter an estimated score for an ungraded assignment if desired.
5. Click **Calculate Current** or **Calculate Estimated**.
6. Use **Clear** to reset the form or **Exit** to close the application.

## Technologies
